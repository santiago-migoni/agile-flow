# Advance compatibility entry

Read [the collaboration protocol](../../references/collaboration-protocol.md) and [the workflow map](../../AGENTS.md). Reuse the current mandate; do not equate “define” with plan-iteration.

- Exploratory problem understanding or a new product idea: follow [discover](../discover/SKILL.md).
- Product behavior, journeys, scope or priority: follow [define](../define/SKILL.md).
- Interface, backend, frontend, data or infrastructure discussion: follow [design](../design/SKILL.md).
- Explicit delivery organization: follow [plan](../plan/SKILL.md).
- Ready, authorized execution or correction: follow [implement](../implement/SKILL.md).

If “continue” is ambiguous, use the existing agreed next step and authorization. Ask only when materially different interpretations remain. Completing a document or receiving a definition does not authorize a new stage. No magic execution phrase is required.
