# Backlog

Read [the workflow map](../../AGENTS.md) and [the iterative lifecycle contract](../../references/iterative-lifecycle.md). Before writing, read [document operations](../../references/document-operations.md), [session protocol](../../references/session-protocol.md), and [authorization](../../references/authorization.md). Reuse sourced decisions and existing authorization. Resolve the product root; never edit the installed plugin cache.

Use the product manager role for priority and the product engineer role for technical impact. Maintain BL needs using update-backlog and reorder-backlog. For a discovery, identify origin, impact and treatment using record-finding. Current-scope defects and necessary implementation details belong to the current work; new capabilities become unassigned BL needs. Material changes need an explicit decision. Do not automatically assign a release or next sprint. Preserve original US identities and link future US work through follows_up when unfinished work is selected again.
