# Adaptive method

Work in a lightweight cycle: understand the problem and value, maintain a purpose-driven backlog, prepare the next testable increment, develop and verify it, review it with the user, and adapt from the result. Keep near-term work detailed and distant work lightweight. Investigations have a question, boundary, and learning result; they are not delivered functionality.

This is a collaboration method, not a requirement for sprints, points, ceremonies, fictional roles, or a document chain. The user controls priorities and functional outcomes; the agent handles authorized technical decisions and reports material uncertainty.
