# Collaboration outcomes

Read [the collaboration protocol](collaboration-protocol.md) for message interpretation, consultative behavior, uncertainty handling and role transitions, and [document ownership](document-ownership.md) before persisting content. [The macro workflow](../AGENTS.md) routes current and compatibility skills.

Discovery and definition produce shared understanding, not an automatic iteration. Design compares solutions; planning organizes a delivery only when the user's mandate covers it. Implementation reuses valid execution authorization. Review records actual feedback and scoped acceptance.

Apply progressive refinement: detail near work and keep distant work lightweight. Use DEEP for product needs and INVEST for user stories where useful; do not fabricate estimates, priority agreement or passing labels. Estimates need a reasoned basis and an explicit provisional status when not agreed. US/NFR/BUG/TCH/SPK share stable story identities but have type-specific content. Criteria and DoD remain on each story.

A benchmark is not a requirement. Investigate ambiguity proportionally, retain sourced facts and distinguish assumptions. Correct affected questions and records when the user clarifies intent; preserve history. Storage integrity is not semantic correctness or agreement.
