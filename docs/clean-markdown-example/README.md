# Clean Markdown example

This directory represents the readable contents of a product's .agile-flow/ folder. It was generated by the schema-4 renderer in an isolated synthetic fixture. Start with [summary.md](summary.md), [constitution.md](constitution.md), [the product need](backlog/BL-0001.md) and [the story](release/v0.1.0/ITER-001/user-stories/US-0001.md).

Technical schemas, baselines, fixture code and local recovery data are omitted: this is a readable exhibit, not a project to resume or migrate into production.
