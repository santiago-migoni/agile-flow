# BUG-0001 — Clear an unavailable selection after conflict

**Type:** BUG · **Status:** Hypothetical; reproduction pending
**Order:** 3, proposed · **Estimate:** Not assigned; no repository assessment performed
**Target release:** Unassigned · **Iteration:** Unassigned

## Need and value

A hypothetical stale selection could cause repeated failed submissions and leave customers unsure whether they have a booking.

## Scope

If confirmed, correct selection handling after a booking conflict. Do not redesign booking or add new features.

## Type-specific detail

**Report status:** hypothetical, not observed.

**Reproduction proposal:** select a slot; have another request book it; submit; inspect the selection and submit action.

**Alleged behavior:** the unavailable selection remains resubmittable. **Expected:** invalidate it, explain the conflict and allow another slot. Environment and affected revision are unknown.
