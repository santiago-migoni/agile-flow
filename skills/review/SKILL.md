# Review a delivery

Read `../../references/session-protocol.md`, `authorization.md`, and `review-and-learning.md` before writing records.

Identify the increment, delivery revision, and scope the user actually evaluated. Record ordinary-language acceptance only when it clearly covers that delivery. Ask for clarification if the accepted scope is ambiguous. Preserve the actual quote or message reference verbatim. Acceptance with outstanding verification remains acceptance only; it does not change a check to passed.

Keep requested corrections tied to existing criteria. Capture a new need in the backlog and explain its scope impact. When a concrete fact supports an improvement, record its adjustment, target cycle, authorization boundary, and how its effect will be observed.

Report the review decision, current independent states, follow-up work, and next step.
